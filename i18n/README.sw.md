# 🇹🇿 Iliyotengenezwa Tanzania

> **Orodha rasmi ya programu zilizojengwa na watengenezaji wa Kitanzania.**

[![Iliyotengenezwa Tanzania](https://img.shields.io/badge/made%20in-tanzania-008751.svg?style=flat-square)](https://github.com/Tanzania-Developers-Community/made-in-tanzania)

**Lugha Nyingine / Other Languages:** [🇬🇧 English](../README.md)

---

Hii si orodha tu — ni onyesho la ubunifu wa uhandisi wa Kitanzania.

Tunakusanya zana za chanzo wazi (_open-source_), maktaba, na programu zilizojengwa na watengenezaji wa Kitanzania. Ikiwa ni ya manufaa, iko wazi kwa umma, na imeundwa na Mtanzania — inastahili kuwepo hapa.

🌍 **[Angalia orodha ya mwingiliano →](https://made-in-tanzania.vercel.app)**

---

## Jinsi ya Kuchangia

Njia ya haraka zaidi: **hariri `website/projects.json`**, endesha `npm run build`, kisha fungua Pull Request.

```jsonc
// website/projects.json — ongeza mradi wako:
{
  "name": "Jina la Mradi Wako",
  "description": "Unafanya nini katika sentensi moja wazi.",
  "emoji": "🚀",
  "tech": ["Python", "API"],
  "author": "jinalakosotamu",
  "authorUrl": "https://github.com/jinalakosotamu",
  "repo": "https://github.com/jinalakosotamu/mradi-wako",
  "stars": 0,
  "letter": "J",
}
```

Kisha endesha:

```bash
npm run validate   # huangalia kama kumbukumbu yako ni sahihi
npm run build      # huzalisha upya README hii
```

Angalia [CONTRIBUTING.md](../CONTRIBUTING.md) kwa miongozo kamili.

## Vigezo vya Mradi

Mradi unastahili kuwepo hapa ukikidhi yafuatayo:

- ✅ Umejengwa na Mtanzania au timu yenye Watanzania
- ✅ Ni chanzo wazi (_open-source_) na leseni iliyo wazi
- ✅ Una maelezo wazi katika faili ya README
- ✅ Una matumizi halisi au thamani ya kujifunza
- ✅ Unaendeshwa au kuna ahadi ya matengenezo

Ikiwa una shaka, fungua **Issue** kwanza uulize — tutakusaidia.
